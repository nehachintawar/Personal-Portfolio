# Personal-Portfolio

A modern personal portfolio built with **React**, **Vite**, **CSS**, and **MUI**. This repo contains a single-page portfolio site with reusable components, a theme context, and build/lint scripts.

---
## Live Preview 

```
https://neha-chintawar-personal-portfolio.vercel.app/
```
---

## 🚀 Quick Start

Prerequisites: Node.js (v16 or newer) and npm/yarn

1. Install dependencies:

```bash
npm install
```

2. Run the development server:

```bash
npm run dev
```

3. Build for production:

```bash
npm run build
```
